
# Makhdoom's Supermarket Analyzer

Ready-to-run Streamlit project for supermarket customer analysis.

## Run locally
1. Create venv (recommended)
   python -m venv venv
   source venv/bin/activate   # or .\venv\Scripts\activate on Windows

2. Install requirements
   pip install -r requirements.txt

3. Run the app
   streamlit run app/supermarket_dashboard_v2.py

The included dataset is at data/supermarket_customers.csv
